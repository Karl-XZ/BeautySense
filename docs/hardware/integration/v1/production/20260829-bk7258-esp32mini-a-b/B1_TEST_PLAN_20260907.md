# 银龄智护 B1 测试计划（2026-09-07）

## 当前已确认

- ESP32-S3 最小系统：PASS
- Flash 4MB / PSRAM 2MB：PASS
- USB 下载 / USB Serial：PASS
- Wi-Fi 扫描 / AP连接 / DHCP：PASS，RSSI 约 -48~-49 dBm
- SENSOR_I2C：GPIO21 SDA / GPIO18 SCL
- PCA9540B 0x70：PASS
- 当前 0x68 IMU：稳定 CHIP_ID=0x27，可按 BMI260 初始化并输出六轴；正式 BMI270 目标仍未 PASS
- 两颗 DRV2605L：已拆除，待重新焊接验证

## Test 1｜电源 / ESP / 基础总线收尾

1. 冷启动至少 5 次：ESP、USB、Serial 稳定。
2. 记录 5V、BAT、SYS_3V3、2.8V、1.5V。
3. 记录空载、ESP运行、Wi-Fi连接时输入电流和发热点。
4. Wi-Fi 做 DNS + HTTP/TCP 互联网访问。
5. 输出 PASS / FAIL / NOT TESTED。

## Test 2｜电池 / 充电 / FPC板间链路

1. BQ24074：5V、BAT、PGOOD、CHG。
2. 有/无电池分别测试。
3. 电池充电、电压变化、充电电流和温升。
4. TPS63021：5V输入和电池输入下 SYS_3V3。
5. TLV75728 2.8V、TLV75515 1.5V。
6. 8Pin FPC：BAT+×2、GND×2、SPK+/SPK−、LRA_B+/LRA_B−逐针验证。
7. B板装好后测板间压降、连续性和弯折稳定性。

## Test 3｜IMU / PCA / DRV2605L

1. 正式 BMI270：CHIP_ID 必须 0x24，再做完整初始化和六轴测试。
2. PCA9540B：0x00 OFF、0x04 CH0、0x05 CH1。
3. 重新焊两颗 DRV2605L 后：CH0/CH1分别只出现一颗 0x5A。
4. 两路 DRV 独立驱动 LRA，Library 6、单效果、GPIO触发。
5. 若使用 INT1/INT2，单独验证中断脚。

## Test 4｜Camera / MIC / Audio

1. Camera 电源轨先测，再做 SCCB 通信。
2. OV5640：识别、DVP出帧、分辨率/帧稳定性。
3. MIC：I2S/数字麦克风时钟、PCM数据、静音和说话样本。
4. MAX98357A：I2S、SD/EN、SPK+/SPK−差分输出；SPK端不得接GND。
5. 两只8Ω骨传导并联：从低音量开始，记录声音、失真、温升、电流。
6. ZTS6672 仅作为候选验证，不自动替代 ICS-43434 基线。

## Test 5｜整机稳定性 / 结构基准

1. 同时运行 Wi-Fi + IMU + Camera + MIC/Audio + Haptic。
2. 电池和5V供电分别测试。
3. 连续运行 30–60 min，记录掉线、I2C错误、掉帧、音频异常、重启。
4. 冷启动至少 20 次。
5. FPC轻微弯折、板边轻压下观察间歇故障。
6. 检查器件高度、接口可达性、天线净空、结构干涉、真实尺寸。
7. 最终按 PCB / BOM / Firmware / Structure 输出 V2 修改项。

## 总体顺序

```text
Test 1 电源/ESP
  ↓
Test 2 电池/充电/FPC
  ↓
Test 3 IMU/PCA/Haptic
  ↓
```
