### I2S Full-Duplex 实测（2026-09-08）

程序：`ESP32_I2S_FULL_DUPLEX_MIC_AMP_TEST_20260908.ino`

共享时钟：

```text
GPIO36 BCLK  -> MIC + MAX98357A
GPIO37 WS    -> MIC + MAX98357A
GPIO38 DIN   <- MIC
GPIO39 DOUT  -> MAX98357A
GPIO40 SD    -> MAX98357A
```


