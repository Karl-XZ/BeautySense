## Test 4｜Camera / MIC / Audio

状态：NEXT

当前优先从不依赖 B 板和 DRV2605L 的 Camera / MIC / Audio 开始。

推荐顺序：

1. Camera 电源轨确认。
2. OV5640 SCCB 识别。
3. OV5640 DVP 出帧。
4. MIC 时钟 / PCM 数据。
5. MAX98357A I²S / SD/EN / BTL 差分输出。
6. 两只 8Ω 骨传导并联，从低音量开始验证声音、失真、温升、电流。
7. ZTS6672 仅作为候选验证，不自动替代 ICS-43434 基线。

## Test 5｜整机稳定性 / 结构基准

1. 同时运行 Wi-Fi + IMU + Camera + MIC/Audio + Haptic。
2. 电池和5V供电分别测试。
3. 连续运行 30–60 min，记录掉线、I2C错误、掉帧、音频异常、重启。
4. 冷启动至少 20 次。
5. FPC轻微弯折、板边轻压下观察间歇故障。
6. 检查器件高度、接口可达性、天线净空、结构干涉、真实尺寸。
7. 最终按 PCB / BOM / Firmware / Structure 输出 V2 修改项。
