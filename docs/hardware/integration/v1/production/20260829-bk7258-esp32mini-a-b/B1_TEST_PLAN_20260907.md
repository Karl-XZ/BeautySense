### Test 5C｜20 次真实断电冷启动

状态：OFFLINE MODE NEXT / Wi-Fi 子项 ENV BLOCKED

用户离开工作室后，原保存的目标 AP 不可达。日志中的 `WIFI INIT FAIL` 是环境条件导致，不能记作 Wi-Fi 硬件 FAIL，也不能记作整板冷启动 FAIL。

该版本用独立 NVS namespace 重新计数，只验证：PSRAM + OV5640 + MIC RX + MAX98357A TX + PCA9540B + BMI260-like IMU。每次真实 POWERON 进入 15 s 并发窗口，PASS 标准：`camErr=txErr=rxErr=imuErr=pcaErr=0`，并且 Camera/IMU/MIC 计数持续增长。Wi-Fi 明确标记为 EXCLUDED / ENV BLOCKED，回到有目标 AP 的环境后再用含 Wi-Fi 版本补 Wi-Fi 冷启动维度。
