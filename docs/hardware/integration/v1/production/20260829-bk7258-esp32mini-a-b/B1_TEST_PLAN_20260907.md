## Test 3｜IMU / PCA / DRV2605L

状态：PARTIAL PASS / PARTIAL BLOCKED

已完成：

1. PCA9540B：0x70 稳定通信。
2. 当前上游 0x68 器件稳定 CHIP_ID=0x27，可按 BMI260 配置完成初始化并输出 Accel/Gyro 六轴数据。
3. INT1 Data Ready：PASS / STRONG。INT1_IO_CTRL=0x0A、INT_LATCH=0x00、INT_MAP_DATA=0x04；启动前约 3 秒存在正常过渡，之后 IRQ 计数稳定约 93~101 次/秒，total 持续增长；INT_STATUS_1 在有效时读到 0xC0。由此确认当前器件 INT1 输出、PCB 走线/焊接、ESP32-S3 GPIO33 输入和 ISR 路径可工作。

说明：每秒打印时 GPIO33 常读到 0，是因为 Data Ready 中断脉冲很短；边沿 ISR 能持续计数才是本项的关键证据。

未完成 / 阻塞：

1. 正式 BMI270：仍需 CHIP_ID=0x24 的真实器件重新验证，并在正式器件上复测六轴与 INT1。
2. 两颗 DRV2605L 当前已拆除，因此 CH0/CH1 0x5A 与双路 LRA 测试暂时不能进行。
