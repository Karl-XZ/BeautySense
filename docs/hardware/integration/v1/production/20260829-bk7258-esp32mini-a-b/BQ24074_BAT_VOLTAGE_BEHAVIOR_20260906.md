# BQ24074 BAT+ 电压波动判断（2026-09-06）

适用：银龄智护 V1 A-ESP / A-BK 共用 BQ24074 PowerPath 充电部分。

## 结论

- 无电池、仅 5V 输入时：BAT 引脚/`BAT+` 出现周期性波动可以是正常行为。BQ24074 会执行电池检测，对 BAT 端电容周期性充放电；TI 文档说明电池缺失时 BAT 端可出现方波/周期波动。
- 已连接正常 1S LiPo 时：`BAT+` 应主要跟随电池电压，通常约 3.x V 到 4.2 V，并随充电缓慢上升。快速、大幅、反复跳变不应直接视为正常，应排查接触不良、保护板动作、焊接问题、充电状态切换或负载脉冲。
- 无 5V、仅电池供电时：`BAT+` 应基本稳定在电池端电压，负载变化会带来一定压降，但不应像无电池检测那样周期性大幅摆动。

## 当前 Bring-up 使用方法

判断 BAT+ 波动前必须记录：

1. 是否接电池。
2. 是否接 5V 输入。
3. BAT+ 波动的最低值/最高值。
4. 波动周期大约多长。
5. SYS_PWR 与 3V3 是否同时稳定。

如果当前是“未接电池 + 5V 输入”，BAT+ 波动本身不应被误判为短路或 BQ24074 损坏。
