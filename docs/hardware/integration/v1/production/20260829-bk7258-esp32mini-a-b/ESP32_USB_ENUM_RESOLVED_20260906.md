# ESP32-S3 USB 枚举问题结论（2026-09-06）

## 状态

`RESOLVED`

## 现象

- ESP32-S3 主板 3V3 约 3.4V，EN 约 3.4V，均稳定。
- 电脑连接 USB 后反复出现连接/断开提示音。
- D+/D- 断电检查无硬短路。
- 两颗 USB 串联电阻实测均约 22Ω。
- 将杜邦线替换为直接使用 USB 数据线线头连接后，现象不变，因此临时飞线质量不是主要根因。

## 根因

测试时遗漏了 ESP32-S3 进入 ROM Download Mode 所需的 `BOOT + EN` 操作流程。

正确操作：

```text
板子上电 / USB 已连接
BOOT → GND，保持
EN   → GND，约 0.5~1 秒
释放 EN
继续保持 BOOT 约 0.5 秒
释放 BOOT
```

执行正确流程后，USB 枚举恢复正常。

## 结论

当前证据表明：

- USB D+/D- 物理链路基本可用；
- 22Ω 串联电阻基本正常；
- USBLC6-2SC6 暂无证据表明存在故障；
- 之前的反复连接/断开不应继续归因于 USB 信号完整性或 ESD 器件；
- 故障根因为 bring-up 操作步骤遗漏，而非当前已确认的硬件器件故障。

## 下一步

1. 使用 esptool/ESP-IDF 工具读取芯片信息。
2. 烧录最小测试程序。
3. 验证复位、BOOT、USB 下载可重复成功。
4. 再依次 bring-up BMI270、PCA9540B、DRV2605L、MIC、MAX98357A、Camera、B板/FPC、电池/充电。

注意：本结论只说明当前 USB 下载链路已能正常进入枚举，不等于整板所有 ESP 模组底部焊点已完成验证。
