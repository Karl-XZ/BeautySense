# ESP32-S3 USB 枚举异常调试记录（2026-09-06）

## 当前状态

- 此前 3.3V 短路根因：ESP32 核心模组底部多焊盘连锡，已修复。
- 3V3 实测约 3.4V，电脑 USB 提示音出现时不掉压。
- EN 实测约 3.4V，未见跟随提示音反复掉电。
- USB D+ 万用表读数约在 3.2V 与 1.6V 之间变化。
- Windows 持续出现 USB 连接/断开提示音。

## 初步判断

主 3.3V 电源稳定，优先将故障范围收敛到 USB 枚举/物理链路，不再优先怀疑 TPS63021 供电掉压。

普通万用表无法显示 USB Full-Speed 实际差分波形，只会显示高速数据活动的平均电压，因此 D+ 在 1.x~3.xV 范围变化不能单独判定异常。

## 下一步

1. Windows 设备管理器记录每次连接时出现的具体设备/错误名称。
2. 断电检查 D+-D-、D+-GND、D--GND 是否存在接近 0Ω 硬短。
3. 分别确认两颗 USB 串联电阻接近 22Ω。
4. USB 临时飞线尽量 <=5cm，D+/D- 紧贴/双绞，GND 短回路。
5. 强制进入 ESP32-S3 ROM 下载模式重新枚举。
6. 若仍失败，重点复查：ESP USB 焊盘 → 22Ω → USBLC6-2SC6 → 飞线/接口。
7. 因核心模组此前存在底部连锡，USB D+/D- 对应焊盘残余桥连/虚焊优先级高。
