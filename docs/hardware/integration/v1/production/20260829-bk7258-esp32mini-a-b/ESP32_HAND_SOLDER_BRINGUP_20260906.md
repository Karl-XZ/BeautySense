# ESP32-S3-MINI-1U 手焊首板 Bring-up 检查流程

适用对象：银龄智护 V1 的 A-ESP 版本，主控 `ESP32-S3-MINI-1U-N4R2`。

## 目标

手焊完成后，不以“能不能上电”作为唯一合格标准，而采用分阶段 Pass/Fail 检查，逐步排除虚焊、桥连、器件装反、错件、供电异常和接口问题。

## 0. 基线器件/测试点

当前 ESP 版关键器件/网络：

- BQ24074RGTR：1S Li-ion charger + PowerPath
- TPS63021DSJR：固定 3.3V Buck-Boost
- TLV75728PDBVR：2.8V LDO
- TLV75515PDBVR：1.5V LDO
- ESP32-S3-MINI-1U-N4R2
- BMI270
- PCA9540B
- DRV2605L ×2
- ICS-43434
- MAX98357A
- USBLC6-2SC6
- 5V TVS + PPTC
- TP_ESP：3V3 / GND / EN / BOOT / UART_TX / UART_RX
- USB D+/D- 调试电容：DNP，首板不焊

## 1. 完全不上电：目检

使用放大镜/显微镜逐区域检查：

- 所有 IC 方向与 Pin1
- ESP 模组方向
- SOT23-5 LDO 方向
- USBLC6-2SC6 方向
- 连接器 Pin1 与 FPC 方向
- 电阻、电容、电感值是否放错
- 焊锡桥连
- 焊盘完全没吃锡
- 引脚悬空/翘脚
- 锡珠、金属碎屑
- 焊锡是否爬到相邻焊盘
- FPC/USB/RF 接口机械焊点

高风险手焊件优先看：QFN/TQFN、VSSOP、LGA/MEMS、细间距 FPC 座、USB ESD 器件。

## 2. 不上电：万用表短路/阻值检查

电池、USB、Camera、LRA、骨传导、FPC 外设全部先断开。

建议测量并记录：

- 5V_IN → GND
- BAT+ → GND
- SYS_PWR/BQ24074 OUT → GND
- 3V3 → GND
- 2V8 → GND
- 1V5 → GND

注意：不要只用蜂鸣档判断“短路”。大电容充电会导致刚接表笔时蜂鸣/阻值低，然后逐渐升高，这是正常现象之一。真正危险的是稳定停留在接近 0Ω 或极低阻值且不变化。

如果某电源轨稳定低于约 5~10Ω，在不了解该轨正常静态阻抗前不要直接上电，应先找桥连/错件。

同时做相邻细间距引脚抽查：尤其 USB D+/D-、I2C SDA/SCL、FPC 相邻 Pin、ESP 模组周边焊盘。

## 3. 连通性检查：查虚焊

断电状态，万用表蜂鸣/低阻档从“器件引脚”量到“下一节点”，不是只量焊盘到焊盘。

典型检查：

- ESP 3V3 pin/焊盘 → 3V3 测试点
- ESP GND → GND
- EN → 上拉/R-C 节点 → TP_EN
- BOOT → 上拉 → TP_BOOT
- USB D+ → 22Ω串阻 → ESD → 接口 D+
- USB D- → 22Ω串阻 → ESD → 接口 D-
- I2C SDA/SCL → 上拉 → BMI270/PCA9540B
- I2S BCLK/WS/DATA → MIC/AMP

测试虚焊时可以轻压器件或轻微弯动线缆，同时观察阻值是否跳变；若跳变，优先怀疑焊点/连接器。

## 4. 第一次上电：必须限流

优先使用可调直流电源，不要第一次就直接插电脑 USB。

推荐从 5V 输入供电：

- 电压：5.0V
- 初始限流：100mA 左右
- 外设全部断开
- 观察数秒

如果马上顶到限流、输入电压塌陷、某器件快速发热：立即断电。

若 100mA 未异常，可逐步提高限流到 200~300mA，之后再根据板子的实际启动电流提高。不要一开始给几安培的无限流电源。

## 5. 首次上电只测电源树

优先测：

```text
5V_IN
  ↓
BQ24074 OUT / SYS_PWR
  ↓
TPS63021
  ↓
3V3
  ├─ ESP32-S3-MINI-1U
  ├─ BMI270/PCA9540B/DRV2605L 等逻辑
  ├─ TLV75728 → 2V8
  └─ TLV75515 → 1V5
```

目标：

- 3V3 应接近 3.3V
- 2V8 应接近 2.8V
- 1V5 应接近 1.5V
- EN 应为有效高电平
- 不应有明显器件快速升温

首板建议把每个电压与输入电流实际值记录下来，不只写“正常”。

## 6. 发热检查

第一次上电 5~20 秒内重点观察：

- BQ24074
- TPS63021
- ESP32-S3-MINI-1U
- TLV75728/TLV75515
- MAX98357A
- USB ESD/TVS

没有热像仪时，可以先断电再用手背/指腹谨慎接近判断异常热源；更推荐热像仪或红外测温。不要长时间给明显短路的器件通电定位。

## 7. ESP 最小系统检查

确认 3V3 正常后，再检查 ESP：

- EN 是否稳定为高
- BOOT 是否默认高
- UART TX 是否有启动信息（如果当前固件/ROM路径支持）
- 进入下载模式是否可控
- PC 是否能识别 USB/JTAG/CDC（取决于当前固件/下载方式）
- 能否读取芯片信息/Flash

如果下载失败，优先排查：3V3、EN、BOOT、USB D+/D- 连续性、22Ω串阻、USB ESD、USB线缆，而不是第一时间怀疑 ESP 模组损坏。

## 8. 外设逐个启用

不要一次把 Camera、音频、LRA、FPC/B板全部接上。

推荐顺序：

1. ESP 最小系统
2. I2C：先扫 PCA9540B/BMI270
3. DRV2605L 通道选择与识别
4. I2S MIC
5. MAX98357A（先无负载/低音量）
6. Camera 电源 2V8/1V5 与 SCCB
7. Camera DVP
8. LRA
9. 骨传导
10. B板/FPC
11. 电池充电/PowerPath

某一步失败，就停在这一层排查，避免多个故障叠加。

## 9. 手焊“合格”建议判据

板子可标记为 `PASS-BRINGUP` 的最低条件：

- 目检无桥连/反装/明显虚焊
- 各主电源轨对地无异常硬短
- 5V 限流上电不顶限流
- 3V3/2V8/1V5 正常
- 无异常发热
- ESP 可进入下载/通信
- USB链路可用（若本版使用USB下载）
- I2C 基础器件可识别
- 轻压/轻摇连接器时电源与通信无跳变

只有“能烧录”不等于整板焊接合格；还需要逐外设功能验收。
