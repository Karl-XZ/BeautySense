# 银龄智护 V1｜2026-08-29 剩余采购缺口

## 一、优先补买

1. **正确规格的 1206 PPTC**
   - 当前 F1 目标：约 `Ihold 0.75 A / Itrip 1.5 A / >= 8~16 V / 1206`。
   - 本次购买的 `BSMD1206-010 / JSMD1206-010` 为 100 mA 级，不能用于主 5 V 输入 F1。
   - 可选同规格族示例：Yageo `SMD1206B075TF/16`、Littelfuse `1206L075/16WR`、Bourns `MF-NSMF075/16X-2`；最终以 Footprint 与供货为准。

2. **BK7258 RF 匹配小料**（A-BK 版本）
   - C48：`1.2 pF`，C0G/NP0
   - C49：`1.0 pF`，C0G/NP0
   - C50：`0.4 pF`，C0G/NP0
   - L4：`3.0 nH / 3.3 nH` 尚未最终冻结
   - R17：`0 Ω` 已有 0603 样品，但仍需确认最终 Footprint
   - 建议 RF 首版不要只买单值：同封装额外准备 2.7/3.0/3.3 nH，以及 0.3/0.4/0.5 pF、1.0/1.2/1.5 pF 作为实测调试余量。

3. **BK 26 MHz 晶振负载电容**
   - `10 pF C0G/NP0 ×2 / 每块 BK 板`
   - 现有订单中的 47 pF/68 pF/100 pF 等不能替代 10 pF。

4. **BK 内部 Buck 的 4.7 µH 电感**
   - `L2/L3 ×2 / 每块 BK 板`
   - 当前 BOM 只冻结到：`4.7 µH；Isat >= 200 mA；DCR <= 500 mΩ`，具体 MPN/Footprint 尚未在采购表冻结。
   - 先从最终 PCB 源工程确认焊盘尺寸，再下单，避免买到尺寸过大的电感。

5. **尚缺的通用阻容值**
   - 电容：`22 µF`、`4.7 µF`、`2.2 µF`；已有 100 nF/1 µF/10 µF 历史库存，但必须确认封装是否与生产 PCB 一致。
   - 电阻：`1.8 kΩ`、`1.5 kΩ`、`46.4 kΩ`、`2.2 kΩ`、`10 kΩ`、`22 Ω`、约 `2 kΩ`、`3.9 Ω`；`4.7 kΩ / 100 kΩ / 0 Ω`已有部分历史库存，同样要核 Footprint。
   - 阻容建议以最终原理图/BOM 导出的封装为准后一次性采购，不要仅按数值购买。

6. **2.4 GHz 外置天线**
   - A-BK：当前 BOM 推荐候选 `AIWP007` / U.FL-IPEX 类 50 Ω FPC 天线，尚未在订单中发现。
   - A-ESP：`ESP32-S3-MINI-1U` 为外置天线版本，也需要兼容其 RF 连接器的 2.4 GHz 天线。
   - 若两个主控不同时测试，可先买 1~2 条兼容天线做 Bring-up；若两版同时装机，则每套各配 1 条。

7. **4Pin 磁吸电源/USB 接口 + 配套线**
   - 电气定义已冻结：`5V / GND / USB D+ / USB D-`。
   - 机械 MPN 尚未冻结，当前订单中未发现对应 4Pin 磁吸件。
   - 这项不要盲买：先确定板端尺寸、触点顺序、磁极方向、额定电流、插拔方向，再成套买板端 + 线端。

## 二、先验证，不建议马上重买

### TPS63021 电感

本次已购：
- BK：`FXL0420-1R5-M`，1.5 µH
- 历史订单：`FXL0420-1R0-M`，1.0 µH

公开参数：
- `FXL0420-1R5-M`：Isat 约 6 A、Irms 约 5 A、DCR 最大约 46 mΩ
- `FXL0420-1R0-M`：Isat 约 7 A、Irms 约 6 A、DCR 最大约 27 mΩ

TPS63021 官方 1.5 µH 推荐示例的饱和电流约 5.1 A，因此 `FXL0420-1R5-M` 从饱和电流角度满足，但 DCR 高于官方低阻示例，效率/温升可能稍差。当前动作应是先核 Footprint 和温升，不必立刻重新购买。

### 数字麦克风

当前订单只有 `ZTS6672`，卖家标为 ICS-43434 兼容替代；没有发现真正的 `ICS-43434` 裸芯片采购。

- 如果严格按当前 BOM 做已知基线：建议准备至少 1~2 颗/模块正品 ICS-43434 做 A/B 对照。
- 如果准备直接采用 ZTS6672：必须先拿到正式 Datasheet，核 Pinout、VDD、I2S timing、灵敏度、SNR、AOP、Bottom-port 声孔与封装，再决定是否改 BOM。

### PCA9540BDP

本次已买 `PCA9540BDP`，但卖家商品标题写“MSOP-8”。NXP `DP` 后缀实际封装必须按官方 Package Drawing 与 PCB Footprint 核对；在未核实前不要再次购买，也不要直接贴片。

### 电池

已买 3.7 V / 1000 mAh 候选 3 只，但仍要核：
- 是否自带保护板；
- 最大持续/峰值放电电流；
- 实际长宽厚；
- 重量；
- 是否带 NTC。

若电池裸包不带保护，BQ24074 本身不能替代完整的电芯过流/过放保护，需要额外的保护方案或改用受保护电池包。

## 三、机械件/接口件：等结构冻结后再买

- J_BAT_B 电池座或焊盘方案
- Bone A/B 线端连接器
- LRA A/B 线端连接器
- 4Pin 磁吸接口具体机械 MPN
- 最终长度的 8Pin FFC/FPC（当前 0.3 m / 0.5 m 仅适合开发裁切）

## 四、建议补的备件（非 BOM 缺口）

首版焊接风险较高，建议额外准备：
- `BK7258QN88616`：再 2~3 颗，但要先确认到货的 8+16/QFN88 订单码是真实匹配；
- `ESP32-S3-MINI-1U-N4R2`：再 1~2 颗；
- OV5640 DVP 模组：再 1 颗；
- 2.4 GHz 天线：至少 2 条；
- 关键连接器各留 20~30% 备件。
