# ESP32 A板 3V3 短路故障记录（2026-09-06）

## 故障现象

手焊完成后的 A-ESP 首板在不上电检查阶段发现 `3V3 -> GND` 为异常低阻/短路，停止直接上电测试并进入短路排查。

## 已确认根因

根因已由实板返修确认：

> ESP32 核心模组/模组底部存在多处焊盘连锡（solder bridge / 连焊）。

这些相邻焊盘的焊锡桥造成 3.3V 网络形成低阻通路，因此表现为 `3V3 -> GND` 硬短路。当前已返修，3.3V 短路现象已解除。

注意：仅依据“3.3V 短路解除”不能反推出所有底部焊盘都已完全正常。若仍存在信号脚之间的残余桥连，可能不会表现为电源短路，而会表现为 USB、UART、BOOT、EN、GPIO 或外设通信异常。

## 返修后的必须确认项

1. 完全断电，重新测 `3V3 -> GND` 电阻，确认不再稳定接近 0Ω。
2. 检查 ESP 模组周围/底部可访问焊盘是否还有焊锡桥、锡珠、偏位。
3. 对关键网络做相邻焊盘短路抽检，重点：
   - 3V3 与 GND
   - EN 与相邻网络
   - BOOT 与相邻网络
   - USB D+ / D-
   - UART TX / RX
   - 关键 GPIO
4. 第一次返修后上电仍使用 5V 可调电源限流，先低电流观察，不直接插电脑 USB。
5. 依次确认 `3V3`、`EN`、ESP 下载/USB、UART，再逐个启用外围。

## 为什么这种故障常见

高密度模组手焊时，以下因素容易造成底部或相邻焊盘桥连：

- 锡膏/焊锡量过多
- 模组放置偏位
- 加热时模组移动
- 焊盘间距小，熔锡在表面张力作用下连成一片
- 助焊剂不足导致锡不易回缩
- 返修时补锡过多

## 后续装配改进

- 模组优先使用钢网控制锡膏量，而不是逐脚堆锡。
- 回流/热风前先精确对位，观察四边基准焊盘。
- 加热过程中不要用镊子推模组。
- 返修优先使用助焊剂 + 吸锡带控制锡量，不要继续大量补锡。
- 焊完后把 `3V3-GND`、`5V-GND` 等主电源轨阻值检查作为强制上电门槛。
- 对隐藏焊盘器件，功能测试前必须做电源轨和关键网络电测，不能只靠外观。
