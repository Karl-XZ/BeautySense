## 仍未闭合的实质问题

### 1. BK7258 L2/L3 4.7 µH 候选不满足当前 Datasheet DCR 上限

BK7258 Datasheet 给出的外部电感要求：

```text
L = 4.7 µH
DCR <= 500 mΩ
Isat >= 200 mA
```

本批 `FTC160808S4R7MBCA`：

```text
L = 4.7 µH
DCR = 585 mΩ
Isat = 1.2 A
Irated = 1 A
Package = 0603 / 1608
```

结论：电流能力足够，但 DCR 超出 500 mΩ 上限，不能作为正式冻结料；需要继续找满足 DCR <= 500 mΩ 的 4.7 µH 电感，或取得 Beken 对该具体应用允许放宽的正式依据。

### 2. ICS-43434 仍未被正式采购料闭合

当前冻结 BOM 仍以 `ICS-43434` 为麦克风基线。已购 `ZTS6672` 仅为兼容候选，在没有正式 Datasheet 与 pinout/I2S/声学验证前，不能等价替代。因此若按冻结 BOM 装板，ICS-43434 仍是缺料。
